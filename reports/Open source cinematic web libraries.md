# Free libraries rebuild GetLayers' cinematic toolkit

You can get almost everything GetLayers.ai sells (cinematic sections, shader backgrounds, gradients, text animations and cursor effects) from free, actively maintained open-source projects. The best fit for Vellox is a small stack that leaves the current architecture alone. It has four parts. First, keep the hand-written WebGL backgrounds. Second, add **Paper Shaders** (Apache-2.0, no attribution, no dependencies) for gradient and grain backgrounds. Third, take text, cursor, marquee and bento pieces from MIT copy-paste registries such as **Magic UI**, **Vengeance UI** and **Motion Primitives**, and from React Bits, which allows use inside a website. Fourth, add **Lenis** (about 5.5 kB) plus native CSS scroll animations and React's built-in `<ViewTransition>` for the cinematic scroll feel. The site's three constraints decide most of the choice. Removing three.js rules out ShaderGradient, Vanta, React Three Fiber and Spline, because each one adds back 230 KB gzip or more. The strict `script-src 'self'` CSP penalises any tool that loads WASM or scenes from a vendor CDN. The commercial status of the site rules out Shadertoy code, Spline Free, Unicorn Studio Free and the Once UI Magic Portfolio template, which are all non-commercial or watermarked. GSAP is now free for commercial use, but it is not open source, and it duplicates framer-motion. Add it only if you want a pinned, scrubbed storytelling section. One open question needs action: Skiper UI, which the site already uses, publishes no licence, so ask its author to confirm the footer credit is enough. This report does not evaluate GetLayers.ai itself.

## Copy-paste registries already cover text, cursor and section effects

The most useful sources for Vellox are shadcn-style registries. They copy one source file into your project instead of adding a runtime npm package, which matches how `src/components/ui/` already holds ported Skiper UI and Vengeance UI pieces. **React Bits** is the largest, with **about 50,400 GitHub stars** and a push on 2026-10-19. Its components fall into five groups: text animations, animations, components, backgrounds and micro-interactions. Each comes in JS/TS and CSS/Tailwind variants, and it offers a shadcn MCP server and an llms.txt for AI agents ([React Bits](https://reactbits.dev/get-started/introduction); [GitHub](https://github.com/DavidHDev/react-bits)). **Magic UI** (MIT, about 22,900 stars) is the polished choice for marketing text and special effects, and is built on React 19 and Tailwind 4 ([GitHub](https://github.com/magicuidesign/magicui); [Magic UI docs](https://magicui.design/docs)). **Vengeance UI** (MIT) runs on the same stack as Vellox: Next 16, React 19 and Tailwind 4. It has 46 components, including pixelated image trails, flip and morph text, cursor cards, animated rays and staggered bento grids ([vengenceui.com](https://www.vengenceui.com); [package.json](https://github.com/Ashutoshx7/VengeanceUI)). **Aceternity UI** has the most dramatic free backgrounds, about 114 free entries by count, among them Aurora, Background Beams, Spotlight, Lamp, Vortex, and Cloud and Dither shaders. It also has text effects such as Text Generate and Encrypted Text, and cursor effects such as Following Pointer and Lens ([Aceternity components](https://ui.aceternity.com/components)).

Star counts and push dates come from the GitHub API on the research date ([component notes sources: Cult UI](https://github.com/nolly-studio/cult-ui), [Kokonut UI](https://github.com/kokonut-labs/kokonutui), [Motion Primitives](https://github.com/ibelick/motion-primitives), [Animate UI](https://github.com/imskyleen/animate-ui)).

These components are cheap to add or expensive depending on what sits under them. Pieces built on Motion or CSS cost almost nothing, because framer-motion already ships on the site. Many Aceternity and React Bits backgrounds are canvas or WebGL loops. React Bits pulls in GSAP, three.js or matter-js only for the components that need them ([pkgpulse](https://www.pkgpulse.com/guides/react-bits-vs-aceternity-magic-ui-2026)). Vengeance UI's own repo depends on three, R3F, GSAP and Paper Shaders, so check each component's imports before you port it ([package.json](https://github.com/Ashutoshx7/VengeanceUI)). The site already has a custom ribbon shader, so a second full-screen WebGL background adds little. **Text reveals, cursor effects, marquees and bento grids add the most value for the smallest cost.** Components written against `motion/react` need only an import rename, because `motion` and `framer-motion` 14.7.0 are the same release under two names ([npm registry](https://registry.npmjs.org/motion)). Most Magic UI and Aceternity effects use hard-coded rainbow or neutral gradients. You must recolour them by hand to keep #3730e8 as the only accent.

## Paper Shaders beats every three.js option for backgrounds

For shader and gradient backgrounds, **Paper Shaders** is the clear winner. Its catalogue includes MeshGradient, grain, dither and dot effects. It is Apache-2.0, and its README says it "can be used in commercial projects without visible attribution". It has zero dependencies, supports React 18 and 19, and was last published on 2026-10-21 ([GitHub paper-design/shaders](https://github.com/paper-design/shaders); [npm registry](https://registry.npmjs.org/@paper-design%2Fshaders-react)). The full React package measures 81 KB gzip on Bundlephobia. One imported component costs much less ([Bundlephobia](https://bundlephobia.com/)). MeshGradient takes a `colors` hex array plus `colorBack`, `distortion`, `swirl` and `speed`, so a near-black base with #3730e8 and a darker indigo works out of the box. The one drawback is that it is still on version 0.0.x, which ships breaking changes, so **pin the exact version** ([GitHub](https://github.com/paper-design/shaders)). **OGL** (public domain, zero dependencies, 33 KB gzip in full) is the lightweight helper if you ever want a small 3D scene without three.js. Its last release was in January 2025, and the library is small and stable ([npm registry](https://registry.npmjs.org/ogl)). **tsParticles** (MIT, engine 14.5 KB gzip, released 2026-10-25) is the choice if you need particles ([npm registry](https://registry.npmjs.org/@tsparticles%2Freact)).

The well-known alternatives all bring back the cost the site removed. **ShaderGradient** (MIT) makes lovely 3D mesh gradients and has a visual configurator, but it needs three, React Three Fiber, three-stdlib and camera-controls as peer dependencies. Three alone is about 181 KB gzip and R3F adds 56 KB, and ShaderGradient's last publish was in December 2025 ([GitHub ruucm/shadergradient](https://github.com/ruucm/shadergradient); [Bundlephobia](https://bundlephobia.com/)). **Vanta.js** is effectively abandoned. Its last release was in 2022, and its examples load three.js r134, while the current version is r186 ([GitHub tengbao/vanta](https://github.com/tengbao/vanta)). React Three Fiber 9 is the right choice if you ever go back to real 3D. It is MIT and requires React 19, but its peer range stops below React 19.4, so a future React upgrade can block on it ([npm registry](https://registry.npmjs.org/@react-three%2Ffiber)).

The hosted design tools are closest to the GetLayers experience, and they are also where the costs hide. **Spline Free** puts a watermark on web exports, Hobby ($15/mo) removes it, and a fully self-hosted export is Enterprise-only. Its runtime is 273 KB gzip plus WASM, and its npm packages carry no licence ([Spline pricing](https://spline.design/pricing); [npm registry](https://registry.npmjs.org/@splinetool%2Fruntime)). **Unicorn Studio Free** is limited to "Personal and non-commercial use" and carries branding. Commercial use and the self-hostable JSON export need the $20/mo Legend plan ([Unicorn Studio pricing](https://www.unicorn.studio/docs/pricing/)). **Rive** runtimes are MIT, but creating new exports has needed a paid plan, from $9/mo, since October 2025 ([Rive blog](https://rive.app/blog/rive-s-new-9-mo-plan)).

## Motion plus Lenis delivers cinematic scroll without GSAP

The site already ships Motion, so the cinematic scroll layer needs only small, complementary additions. **Lenis** (MIT, about 5.5 kB gzip, released 2026-10-15) is the standard smooth-scroll library. It wraps native scroll, so sticky positioning, anchor links and accessibility keep working. It turns off smoothing automatically for visitors who ask for reduced motion, and it ships `lenis/react` ([Lenis GitHub](https://github.com/darkroomengineering/lenis)). Its known limits are smoothing capped at 60 fps in Safari, no support for CSS scroll-snap, and smoothing that stops over iframes. **Native CSS scroll-driven animations** (`animation-timeline: view()`) now reach about 88% of users, including Safari 26 and recent Firefox desktop. They run off the main thread, which makes them the best option on mobile for simple reveals and parallax, as long as they sit behind an `@supports` fallback ([caniuse](https://caniuse.com/mdn-css_properties_animation-timeline)). For page transitions, the Next 16.3.2 guide installed in this repo says React's `<ViewTransition>` works in the App Router "with no configuration". Older 16.2 docs described an experimental flag ([Next.js View Transitions guide](https://nextjs.org/docs/app/guides/view-transitions)). You can also cut Motion's own cost. Switching from `motion` to `m` + `LazyMotion` brings the initial load to just over 5 kB, plus 24 kB for `domAnimation` ([Motion docs](https://motion.dev/docs/react-reduce-bundle-size)).

**GSAP** is the strongest case for a second animation library. All its former paid plugins, including SplitText and MorphSVG, became free after the Webflow acquisition. SplitText was rewritten to be about 50% smaller and to support screen readers ([Webflow blog](https://webflow.com/blog/gsap-becomes-free); [SplitText rewrite](https://webflow.com/blog/gsap-splittext-rewrite)). The important detail is that free Motion does not include `splitText`, which is Motion+ only ([Motion SplitText](https://motion.dev/docs/split-text)). GSAP's licence is proprietary freeware, not open source. It allows commercial websites, but Webflow can change the terms (older versions stay usable), and it forbids building a tool that competes with Webflow's visual animation builder ([GSAP Standard License](https://gsap.com/standard-license)). Core plus ScrollTrigger plus SplitText adds about 50 kB gzip on top of Motion ([jsDelivr gsap 3.15.0](https://cdn.jsdelivr.net/npm/gsap@3.15.0/dist/)). That cost is reasonable for one pinned, scrubbed storytelling section. It is pure duplication if you use GSAP only for fade-ins. Skip Theatre.js (public repo inactive since 2024), Barba.js (conflicts with the Next router), Popmotion and SplitType (both stale) ([npm registry](https://registry.npmjs.org/); [Theatre.js GitHub](https://github.com/theatre-js/theatre)).

## Licence traps hide in galleries, templates and generators

The riskiest material is not in npm libraries, which are almost all MIT, Apache-2.0 or public domain. It is in the places people copy code from. **Shadertoy's default licence is CC BY-NC-SA 3.0**, which forbids commercial use. Use it to learn, but do not paste its shaders into a client-facing site without the author's permission ([three.js manual](https://threejs.org/manual/en/shadertoy.html)). The **Once UI Magic Portfolio** template is CC BY-NC 4.0, and its README says "Commercial usage is not allowed" without a Pro licence, although Once UI Core and its Next.js starter are MIT ([GitHub magic-portfolio](https://github.com/once-ui-system/magic-portfolio)). **Hero Patterns** is CC BY 4.0, so it needs a credit ([heropatterns.com](https://heropatterns.com/)). **21st.dev** is a marketplace with no blanket open licence. Its terms ban redistribution, and each component keeps its author's licence ([21st.dev terms](https://21st.dev/terms)). React Bits and Animate UI use "MIT + Commons Clause". That allows use "for any commercial purpose" on a website, but forbids reselling the components, and you must keep the copyright notice in ported files ([React Bits LICENSE](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md)). **Aceternity's** free tier and **Skiper UI** publish no clear open-source licence. Skiper's `/license` page returns 404, and only a third-party listing claims free users must give attribution ([skiper-ui.com](https://skiper-ui.com); [Tailkits](https://tailkits.com/components/skiper-ui/)). Vellox's footer credit is a sensible precaution, but it is not a confirmed licence.

Some sources are clean. **Public CodePen pens are automatically MIT**, so add a header comment with the author and pen URL when you port one ([CodePen licensing](https://blog.codepen.io/documentation/licensing/)). Uiverse's 3,000+ CSS/Tailwind elements are MIT, with attribution optional, but the repo has not been updated since September 2024 ([GitHub uiverse-io/galaxy](https://github.com/uiverse-io/galaxy)). Codrops demos are MIT "if not specifically mentioned otherwise". That covers the code, not bundled photos or fonts ([Codrops licensing](https://tympanus.net/codrops/?p=7319)). For 3D textures and HDRIs, **Poly Haven** and **Kenney** are CC0, with no attribution needed ([Poly Haven licence](https://polyhaven.com/license); [Kenney](https://kenney.nl/support)). For the AI-agent workflow, Anthropic's `frontend-design` skill is Apache-2.0 ([GitHub](https://github.com/anthropics/skills/tree/main/skills/frontend-design)). The shadcn MCP server installs into Claude Code with `pnpm dlx shadcn@latest mcp init --client claude` and can browse any spec-compliant registry ([shadcn MCP docs](https://ui.shadcn.com/docs/mcp)). It needs a `components.json` file, which this repo does not have yet.

The strict CSP adds a technical filter. Paper Shaders, OGL, tsParticles, Lenis, Motion and GSAP are bundled with your own code, so they run under `script-src 'self'` without changes. **Rive and dotLottie fetch their WASM files from unpkg or jsdelivr by default.** Both can self-host the file through `setWasmUrl` ([Rive docs](https://rive.app/docs/runtimes/react/preloading-wasm); [dotLottie CSP guide](https://github.com/LottieFiles/dotlottie-web/wiki/CSP-and-WASM-Self%E2%80%90Hosting-Guide)). Even self-hosted, WASM generally needs `'wasm-unsafe-eval'` added to the CSP. That is standard browser behaviour rather than something these vendors document, so test it before you rely on it. Hosted Spline and Unicorn scenes would also need vendor domains opened in `connect-src`.

## Recommended shortlist for the Vellox site

This section is for the site owner. Each line says what to use, what it gives you, and what to watch for. All of these are free for a commercial site.

| Priority | Use this | What it gives you | Watch out for |
|---|---|---|---|
| 1 | **Keep the current custom WebGL backgrounds** | The hero already has a cinematic, fast, on-brand background | Nothing. Do not replace it with a heavier library. |
| 2 | **Paper Shaders** (one component at a time) | Extra animated gradients, grain and dither backgrounds in your indigo | Ask the agent to pin the exact version number |
| 3 | **Lenis** | Smooth, "premium" scrolling across the whole site | Ask for it to respect reduced-motion (it does by default) |
| 4 | **Built-in CSS scroll animations and React `<ViewTransition>`** | Fade-in, parallax and page-to-page transitions at zero download cost | Older browsers simply skip the animation, which is fine |
| 5 | **Magic UI, Vengeance UI, Motion Primitives** (MIT) | Text reveals, cursor effects, marquees, bento grids | Recolour to #3730e8; avoid pieces that pull in three.js |
| 6 | **React Bits** | The largest free set of text and cursor effects | Fine on your site; keep the copyright line in each file |
| 7 (optional) | **GSAP** | One "scroll-to-play" pinned storytelling section | Adds about 50 kB; use it for one section only, not everywhere |

The list of things to avoid is just as important. Do not use ShaderGradient, Vanta, React Three Fiber or Spline unless you decide to accept the three.js weight again. Do not paste code from Shadertoy, and do not use Unicorn Studio Free, Spline Free or the Magic Portfolio template, because their free terms forbid commercial use or add a watermark. Treat 21st.dev components and Aceternity's free pieces as "check before use". **Send Skiper UI's author (Gxuri) a short message to confirm that your footer credit meets their terms.**

When you brief Claude Code, a plain instruction like this works well: "Port the [name] component from [Magic UI / React Bits / Vengeance UI] into `src/components/ui/` as a client component. Use framer-motion, recolour it to #3730e8 on a dark background, lazy-load it, pause it off-screen, respect reduced motion, and keep the original licence notice at the top of the file." That one sentence covers licensing, performance and brand fit.

## Conclusion

The main lesson is that GetLayers' value lies in curation and prompts, not in technology that only it owns. Every effect category it covers has a free, maintained, permissive counterpart, and the shadcn MCP server combined with a brand-aware project instruction file reproduces most of the "prompt library" experience inside Claude Code. The real choices for Vellox are about weight and licence, not availability. The decision to drop three.js now works as a useful filter: it removes the most fashionable options (ShaderGradient, Spline, R3F scenes) and points toward lighter, more distinctive work built on CSS, Motion and small shaders.

There are two uncertainties to track. Paper Shaders' 0.0.x versioning means the main background recommendation will churn until it reaches 1.0, and GSAP's licence depends on Webflow's goodwill rather than an open-source guarantee. The most likely future problem is licensing on the copy-paste side, not on the npm side. As the site gathers components from many registries, keeping a short provenance note (source, licence, URL) in each ported file costs little now and saves real trouble later.
